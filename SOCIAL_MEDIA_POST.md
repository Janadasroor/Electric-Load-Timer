## Reddit Post (r/arduino, r/esp8266, r/androiddev)

**Title:** [Project] ESP8266 Load Timer - WiFi-enabled smart scheduler with Android app

**Body:**

Hey everyone! 👋

I just finished my ESP8266 Load Timer project and wanted to share it with the community. It's a complete IoT solution for scheduling electrical loads (lights, fans, pumps, etc.) with a beautiful Android app.

**What it does:**
- Creates a WiFi network that your phone connects to
- Lets you set ON/OFF schedules via Android app or web browser
- Automatically controls a relay based on the schedule
- Saves schedules to EEPROM (survives power cycles)
- Handles complex schedules (even ones that cross midnight!)

**Android App Features:**
- Modern Material 3 UI with dark theme
- Full English/Arabic localization with RTL support
- Real-time status monitoring
- Activity logging
- Settings page

**ESP8266 Features:**
- RESTful API for mobile app
- Embedded web interface for browser control
- Time tracking without RTC (syncs from phone)
- Persistent EEPROM storage

**Tech Stack:**
- ESP8266 (Arduino framework)
- Android (Kotlin + Jetpack Compose)
- MVVM architecture with Hilt DI
- Retrofit for networking

**Use Cases:**
- Automated irrigation
- Scheduled lighting
- Water pump timers
- HVAC control
- Any time-based automation

The project is fully open source! Check out the GitHub repo for complete documentation, wiring diagrams, and setup instructions.

**What I learned:**
- Building bilingual Android apps with RTL support
- ESP8266 web server development
- EEPROM data persistence
- RESTful API design
- Material Design 3 implementation

Happy to answer any questions! 🚀
